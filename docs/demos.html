1. Introduction

La composition typographique moderne trouve ses racines dans les travaux fondateurs de Knuth [1] sur TeX.

LaTeX, developpe par Lamport [2], a democratise ces outils aupres de la communaute scientifique.

Des etudes recentes [3], [4] montrent l'interet croissant pour des alternatives plus modernes.

2. Conclusion

NovaType represente l'evolution naturelle de ces systemes [5].

References

  1. D. E. Knuth, The TeXbook, Addison-Wesley, 1984.
  2. L. Lamport, LaTeX: A Document Preparation System, Addison-Wesley, 1994.
  3. J. Smith et al., "Modern typesetting systems," J. Doc. Eng., vol. 12, no. 3, pp. 45-62, 2020.
  4. M. Jones, "Alternatives to LaTeX," TUGboat, vol. 42, no. 1, pp. 12-18, 2021.
  5. L. Madje and M. Haug, "Typst: A new approach," J. Doc. Eng., vol. 15, no. 2, pp. 112-128, 2023.

NovaType: A Modern Approach to Scientific Document Composition

Jean Dupont

Universite de Paris
jean.dupont@univ-paris.fr

Marie Martin

CNRS

Abstract - This paper presents NovaType, a modern document composition system that combines the typographic quality of LaTeX with an intuitive syntax and instant compilation.

Keywords: typesetting, scientific writing, Typst

I. INTRODUCTION

NovaType addresses the limitations of existing document preparation systems...

A. System Architecture

The core architecture consists of:

  1. Incremental compiler
  2. Schema validator
  3. Citation manager
  4. Plot generator

III. RESULTS

Our evaluation shows significant improvements in productivity (34% reduction in writing time).

IV. CONCLUSION

NovaType represents a viable alternative for scientific document preparation.

Pret a essayer ?

Installez NovaType en quelques secondes et commencez a creer vos documents. 

# Installation
$ cargo install nova-cli

# Creer un nouveau projet
$ nova init mon-article --template ieee-article

# Compiler et ouvrir
$ nova compile main.typ --open

# Mode watch (auto-recompilation)
$ nova watch main.typ
