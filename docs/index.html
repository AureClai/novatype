La composition typographique reimaginee

NovaType combine la puissance de LaTeX avec une syntaxe moderne et intuitive. Creez des documents scientifiques professionnels avec une compilation instantanee, des citations intelligentes et des visualisations de donnees integrees.

Commencer Voir les demos 
// Installation rapide
$ nova init mon-article
$ nova compile main.typ --open

// Votre premier document
#set document(title: "Mon Article")
= Introduction
Bienvenue dans *NovaType*!

Pourquoi NovaType ?

Une solution complete pour la redaction scientifique moderne, construite sur les meilleures technologies.

Compilation Instantanee

Visualisez vos modifications en temps reel. Fini les longues attentes de compilation LaTeX.

Syntaxe Intuitive

Une syntaxe claire et lisible, inspiree de Markdown mais avec toute la puissance necessaire.

Citations Intelligentes

BibTeX, CrossRef API, Zotero. Gerez vos references avec des styles academiques (APA, IEEE, Chicago...).

Visualisation de Donnees

Creez des graphiques directement depuis vos CSV/JSON. Line, Bar, Scatter, Pie et plus encore.

Templates Professionnels

IEEE, Nature, rapports, presentations, CV... Demarrez rapidement avec nos modeles pre-configures.

WebAssembly

Compilez vos documents directement dans le navigateur. Aucune installation requise pour vos utilisateurs.

Simple et Puissant

Decouvrez la syntaxe NovaType a travers des exemples concrets.

// Configuration du document
#set document(title: "Mon Article Scientifique", author: "Dr. Martin")
#set page(paper: "a4", margin: 2.5cm)
#set text(font: "Arial", size: 11pt, lang: "fr")

// Titre centre
#align(center)[
  #text(size: 24pt, weight: "bold")[Titre du Document]
  #v(1em)
  Auteur | #datetime.today().display()
]

// Contenu
= Introduction

Votre texte ici avec du *gras* et de l'_italique_.

= Methodologie

- Premier point
- Deuxieme point
- Troisieme point
// Equations en ligne
La formule d'Euler : $ e^(i pi) + 1 = 0 $

// Equations numerotees
$ integral_(-infinity)^(+infinity) e^(-x^2) dif x = sqrt(pi) $ <eq:gauss>

Voir l'equation @eq:gauss pour la demonstration.

// Matrices
$ bold(A) = mat(
  a_(11), a_(12);
  a_(21), a_(22)
) $

// Systemes d'equations
$ cases(
  x + y = 10,
  x - y = 2
) $
// Frontmatter YAML avec bibliographie
---
title: "Mon Article"
bibliography: "references.bib"
citation_style: "ieee"
---

// Citation simple
Selon les travaux de @knuth1984, la typographie...

// Citation avec page
Comme mentionne dans @lamport1994[p. 42]...

// Citations multiples
Plusieurs etudes @smith2020 @jones2021 confirment...

// Bibliographie automatique
#bibliography("references.bib", style: "ieee")
// Graphique depuis CSV
#nova-plot(
  data: "data.csv",
  type: "line",
  title: "Evolution temporelle",
  x-label: "Temps (s)",
  y-label: "Valeur"
)

// Graphique en barres
#nova-plot(
  data: "results.json",
  type: "bar",
  title: "Comparaison des methodes",
  colors: ("#2563eb", "#10b981", "#f59e0b")
)

// Nuage de points
#nova-plot(
  data: "correlation.csv",
  type: "scatter",
  title: "Correlation X-Y",
  trend-line: true
)

Templates Professionnels

Demarrez rapidement avec nos modeles pre-configures pour tous vos besoins.

Article

Articles generaux et documents academiques simples.

nova init -t article

IEEE

Format officiel IEEE pour conferences et journaux.

nova init -t ieee-article

Nature

Style Nature pour publications scientifiques.

nova init -t nature-article

Report

Rapports techniques et business.

nova init -t report

Book

Livres et documents longs avec chapitres.

nova init -t book

Presentation

Slides et presentations professionnelles.

nova init -t presentation

CV

Curriculum vitae et resumes elegants.

nova init -t cv

Custom

Creez vos propres templates.

nova template new
