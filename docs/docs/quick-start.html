Demarrage rapide

Creez votre premier document NovaType en 5 minutes.

Etape 1 : Creer un projet

Ouvrez votre terminal et executez :

$ nova init mon-premier-article
Creating project 'mon-premier-article'...
  Created main.typ
  Created nova.toml
  Created references.bib
  Created .gitignore
Done! Project created successfully.

$ cd mon-premier-article

Etape 2 : Editer le document

Ouvrez main.typ dans votre editeur prefere et remplacez le contenu par :

// Configuration du document
#set document(title: "Mon Premier Article", author: "Votre Nom")
#set page(paper: "a4", margin: 2.5cm)
#set text(font: "Arial", size: 11pt, lang: "fr")
#set heading(numbering: "1.1")

// Page de titre
#align(center)[
  #v(3cm)
  #text(size: 24pt, weight: "bold")[Mon Premier Article NovaType]
  #v(1cm)
  #text(size: 14pt)[Votre Nom]
  #v(0.5cm)
  #datetime.today().display("[day] [month repr:long] [year]")
]

#pagebreak()

= Introduction

Bienvenue dans NovaType ! Ce document presente les fonctionnalites
de base du systeme de composition typographique.

NovaType permet de creer des documents *professionnels* avec une
syntaxe _simple_ et _intuitive_.

= Conclusion

Felicitations ! Vous avez cree votre premier document NovaType.

Etape 3 : Compiler et visualiser

$ nova compile main.typ --open

Le document PDF s'ouvre automatiquement dans votre lecteur par defaut.

Felicitations !

Vous avez cree votre premier document NovaType. Le PDF genere contient une page de titre, des sections numerotees, des listes et des equations mathematiques.

Etape 4 : Mode watch (optionnel)

Pour recompiler automatiquement a chaque modification :

$ nova watch main.typ
Watching main.typ for changes...
Press Ctrl+C to stop.

Chaque fois que vous sauvegardez le fichier, le PDF est regenere instantanement.
