Visualisation de donnees

Le module nova-plot permet de creer des graphiques SVG directement dans vos documents a partir de fichiers CSV ou JSON.

Types de graphiques

Type Description Utilisation typique
line Graphique en lignes Series temporelles, evolution
bar Graphique en barres Comparaisons, distributions
scatter Nuage de points Correlations, regressions
pie Diagramme circulaire Proportions, pourcentages
area Graphique d'aire Volumes, cumuls

Syntaxe de base

// Graphique depuis un fichier CSV
#nova-plot(
  data: "data.csv",
  type: "line",
  title: "Mon graphique"
)

Parametres disponibles

Parametre Type Description
data string Chemin vers le fichier CSV ou JSON
type string Type de graphique (line, bar, scatter, pie, area)
title string Titre du graphique
x-label string Label de l'axe X
y-label string Label de l'axe Y
width length Largeur du graphique (defaut: 100%)
height length Hauteur du graphique (defaut: 300pt)
colors array Palette de couleurs personnalisee
legend bool Afficher la legende (defaut: true)
grid bool Afficher la grille (defaut: true)

Format des donnees

CSV

// data.csv
x,series1,series2,series3
2020,10,15,8
2021,15,20,12
2022,25,22,18
2023,30,28,25
2024,35,32,30

JSON

// data.json
{
  "labels": ["2020", "2021", "2022", "2023", "2024"],
  "datasets": [
    {
      "name": "Series 1",
      "values": [10, 15, 25, 30, 35]
    },
    {
      "name": "Series 2",
      "values": [15, 20, 22, 28, 32]
    }
  ]
}

Exemples par type

Graphique en lignes

#nova-plot(
  data: "evolution.csv",
  type: "line",
  title: "Evolution temporelle",
  x-label: "Annee",
  y-label: "Valeur",
  colors: ("#2563eb", "#10b981", "#f59e0b")
)

Graphique en barres

#nova-plot(
  data: "comparison.csv",
  type: "bar",
  title: "Comparaison des methodes",
  x-label: "Methode",
  y-label: "Score"
)

Nuage de points avec regression

#nova-plot(
  data: "correlation.csv",
  type: "scatter",
  title: "Correlation X-Y",
  x-label: "Variable X",
  y-label: "Variable Y",
  trend-line: true,
  trend-color: "#ef4444"
)

Diagramme circulaire

// Distribution des categories
#nova-plot(
  data: "distribution.csv",
  type: "pie",
  title: "Repartition par categorie",
  show-percentages: true
)

Graphique d'aire

#nova-plot(
  data: "cumulative.csv",
  type: "area",
  title: "Evolution cumulative",
  stacked: true,
  opacity: 0.7
)

Personnalisation avancee

Palette de couleurs

// Couleurs personnalisees
#nova-plot(
  data: "data.csv",
  type: "bar",
  colors: (
    "#2563eb",  // Bleu
    "#10b981",  // Vert
    "#f59e0b",  // Orange
    "#ef4444",  // Rouge
    "#8b5cf6"   // Violet
  )
)

Dimensions

#nova-plot(
  data: "data.csv",
  type: "line",
  width: 80%,
  height: 250pt
)

Style des axes

#nova-plot(
  data: "data.csv",
  type: "line",
  x-min: 0,
  x-max: 100,
  y-min: 0,
  y-max: 50,
  x-ticks: 5,
  y-ticks: 10
)

Integration avec figure

#figure(
  nova-plot(
    data: "results.csv",
    type: "bar",
    title: none,  // Le titre sera la caption
    height: 200pt
  ),
  caption: [Comparaison des performances des differentes methodes],
) <fig:results>

Comme le montre la @fig:results, notre methode surpasse...

Donnees en ligne

Vous pouvez egalement specifier les donnees directement :

#nova-plot(
  data: (
    labels: ("A", "B", "C", "D"),
    values: (25, 40, 30, 55)
  ),
  type: "bar",
  title: "Donnees en ligne"
)
Note technique

nova-plot genere des graphiques SVG, ce qui garantit une qualite vectorielle parfaite quelle que soit la resolution d'export (PDF, impression haute qualite, etc.).

Exemple complet

= Resultats experimentaux

== Performance des modeles

#figure(
  nova-plot(
    data: "benchmark.csv",
    type: "bar",
    x-label: "Modele",
    y-label: "F1-Score",
    colors: ("#94a3b8", "#94a3b8", "#94a3b8", "#2563eb"),
    height: 220pt
  ),
  caption: [Comparaison des F1-Scores]
) <fig:f1>

Les resultats presentes en @fig:f1 montrent que notre
approche (en bleu) surpasse significativement les baselines.
