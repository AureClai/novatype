Templates

NovaType inclut des templates professionnels pour differents types de documents. Utilisez-les comme point de depart ou creez vos propres modeles.

Templates disponibles

article

Article simple pour documents generaux. Ideal pour commencer.

nova init mon-doc -t article

Champs requis: title
Champs optionnels: author, date, abstract

ieee-article

Format officiel IEEE pour conferences et journaux scientifiques.

nova init paper -t ieee-article

Champs requis: title, authors
Champs optionnels: abstract, keywords, bibliography

nature-article

Style Nature pour publications dans les journaux Nature.

nova init research -t nature-article

Champs requis: title, authors
Champs optionnels: abstract, keywords, affiliations

report

Rapports techniques et business avec table des matieres.

nova init rapport -t report

Champs requis: title
Champs optionnels: author, date, organization, version

book

Livres et documents longs avec support de chapitres.

nova init livre -t book

Champs requis: title, author
Champs optionnels: publisher, year, isbn

presentation

Slides et presentations professionnelles.

nova init slides -t presentation

Champs requis: title
Champs optionnels: author, date, event

cv

Curriculum vitae et resumes elegants.

nova init mon-cv -t cv

Champs requis: name
Champs optionnels: email, phone, address, linkedin

Utiliser un template

Initialisation

# Creer un projet avec un template
$ nova init mon-article --template ieee-article

# Se deplacer dans le projet
$ cd mon-article

# Editer le fichier principal
$ code main.typ

Structure d'un projet

mon-article/
├── main.typ          # Document principal avec frontmatter
├── nova.toml         # Configuration du projet
├── references.bib    # Bibliographie BibTeX
└── .gitignore

Creer un template personnalise

Structure d'un template

mon-template/
├── template.toml     # Metadonnees et schema
├── main.typ          # Code Typst du template
└── schema.json       # Schema JSON (optionnel)

template.toml

[template]
name = "mon-template"
description = "Mon template personnalise"
version = "1.0.0"
author = "Votre Nom"

[schema]
required = ["title", "author"]
optional = ["date", "abstract", "keywords"]

Commandes de gestion

# Creer un nouveau template
$ nova template new mon-template

# Lister les templates installes
$ nova template list

# Informations sur un template
$ nova template info ieee-article

# Installer un template externe
$ nova template install ./chemin/vers/template

Personnalisation

Modifier les couleurs

// Definir vos couleurs personnalisees
#let primary = rgb("#your-color")
#let secondary = rgb("#your-color")
#let accent = rgb("#your-color")

Modifier les polices

// Police principale
#set text(font: "Georgia", size: 11pt)

// Police pour les titres
#show heading: set text(font: "Helvetica")

Modifier les marges

// Marges personnalisees
#set page(
  paper: "a4",
  margin: (top: 3cm, bottom: 2cm, left: 2.5cm, right: 2.5cm)
)
