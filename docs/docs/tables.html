Tableaux

Creez des tableaux professionnels avec une syntaxe simple et flexible.

Tableau simple

#table(
  columns: 3,
  [*Nom*], [*Age*], [*Ville*],
  [Alice], [25], [Paris],
  [Bob], [30], [Lyon],
  [Charlie], [35], [Marseille],
)

Tableau avec figure et legende

#figure(
  table(
    columns: 3,
    [*Methode*], [*Precision*], [*Rappel*],
    [Baseline], [0.72], [0.68],
    [Model A], [0.85], [0.82],
    [NovaType], [0.94], [0.91],
  ),
  caption: [Comparaison des performances],
) <tab:results>

Les resultats du @tab:results montrent...

Largeur des colonnes

// Largeur automatique
#table(columns: 3, ...)

// Largeur fixe
#table(columns: (5cm, 3cm, 4cm), ...)

// Largeur proportionnelle
#table(columns: (1fr, 2fr, 1fr), ...)

// Mixte
#table(columns: (auto, 1fr, 2cm), ...)

Alignement

#table(
  columns: 3,
  align: (left, center, right),
  [Gauche], [Centre], [Droite],
  [texte], [texte], [texte],
)

Bordures et espacement

// Bordure personnalisee
#table(
  columns: 3,
  stroke: 0.5pt + gray,
  [A], [B], [C],
  [1], [2], [3],
)

// Sans bordure
#table(
  columns: 3,
  stroke: none,
  [A], [B], [C],
)

// Espacement interne
#table(
  columns: 3,
  inset: 10pt,
  [A], [B], [C],
)

Couleurs et styles

#table(
  columns: 4,
  fill: (col, row) => {
    if row == 0 { rgb("#2563eb") }
    else if calc.odd(row) { rgb("#f1f5f9") }
    else { white }
  },
  table.header(
    #text(fill: white)[*Col 1*],
    #text(fill: white)[*Col 2*],
    #text(fill: white)[*Col 3*],
    #text(fill: white)[*Col 4*],
  ),
  [A], [B], [C], [D],
  [E], [F], [G], [H],
  [I], [J], [K], [L],
)

Fusion de cellules

#table(
  columns: 3,
  // En-tete fusionne
  table.cell(colspan: 3)[*Titre general*],
  [Col A], [Col B], [Col C],
  [1], [2], [3],

  // Fusion verticale
  table.cell(rowspan: 2)[Multi], [a], [b],
  [c], [d],
)

En-tetes repetes

#table(
  columns: 3,
  table.header(
    [*Nom*], [*Valeur*], [*Unite*],
  ),
  ..data.map(row => (row.nom, row.valeur, row.unite)).flatten()
)

Tableau de donnees

// Definir les donnees
#let data = (
  ("Janvier", 1200, +5%),
  ("Fevrier", 1350, +12%),
  ("Mars", 1100, -18%),
)

// Generer le tableau
#table(
  columns: 3,
  [*Mois*], [*Ventes*], [*Variation*],
  ..data.flatten()
)

Style academique

#figure(
  table(
    columns: (1fr, auto, auto, auto),
    stroke: none,
    align: (left, center, center, center),
    inset: (x: 8pt, y: 6pt),

    // Ligne superieure
    table.hline(stroke: 1pt),
    [*Variable*], [*N*], [*Moyenne*], [*ET*],
    table.hline(stroke: 0.5pt),

    [Age], [150], [34.5], [12.3],
    [Taille], [150], [172.1], [8.7],
    [Poids], [148], [71.2], [14.5],

    // Ligne inferieure
    table.hline(stroke: 1pt),
  ),
  caption: [Statistiques descriptives de l'echantillon],
) <tab:stats>
Convention academique

Pour les articles scientifiques, utilisez le style "trois lignes" (haut, sous en-tete, bas) sans bordures verticales.
