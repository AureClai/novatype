Syntaxe de base

NovaType utilise la syntaxe Typst, un langage de balisage moderne et expressif. Voici les elements fondamentaux.

Modes d'ecriture

NovaType possede trois modes principaux :

Mode Description Exemple
Markup Texte avec mise en forme Texte *gras* et _italique_
Code Fonctions et logique #set text(size: 12pt)
Math Equations mathematiques $ x^2 + y^2 = z^2 $

Texte et paragraphes

Le texte brut est ecrit directement. Les paragraphes sont separes par une ligne vide.

Ceci est un premier paragraphe. Il peut s'etendre
sur plusieurs lignes dans le code source.

Ceci est un second paragraphe, separe du premier
par une ligne vide.

Mise en forme du texte

Syntaxe Resultat Description
*gras* gras Texte en gras
_italique_ italique Texte en italique
`code` code Code en ligne
*_gras italique_* gras italique Combinaison
~indice~ H2O Indice (subscript)
^exposant^ x2 Exposant (superscript)

Titres et sections

Les titres utilisent le signe =. Le nombre de = determine le niveau :

= Titre de niveau 1

== Titre de niveau 2

=== Titre de niveau 3

==== Titre de niveau 4

Pour activer la numerotation automatique :

#set heading(numbering: "1.1")   // 1, 1.1, 1.1.1
#set heading(numbering: "I.A.1") // I, I.A, I.A.1
#set heading(numbering: "1.")   // 1., 1.1., 1.1.1.

Blocs de code

// Code en ligne
La fonction `print()` affiche du texte.

// Bloc de code
```python
def hello():
    print("Hello, World!")
```

// Bloc de code avec typst
#raw(lang: "python", block: true, `
def hello():
    print("Hello!")
`)

Fonctions de base

Les fonctions commencent par # :

// Espacement vertical
#v(1cm)        // 1 centimetre
#v(1em)        // 1 taille de police

// Espacement horizontal
#h(1cm)

// Saut de page
#pagebreak()

// Alignement
#align(center)[Texte centre]
#align(right)[Texte a droite]

// Bloc avec style
#block(fill: rgb("#f0f0f0"), inset: 1em)[
  Contenu du bloc
]
Astuce

Les crochets [] contiennent du contenu markup, tandis que les parentheses () contiennent des arguments de fonction.
