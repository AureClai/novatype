Configuration

Personnalisez NovaType avec les fichiers de configuration projet et globaux.

Fichier nova.toml

Chaque projet NovaType peut avoir un fichier nova.toml a la racine :

# nova.toml - Configuration du projet

[project]
name = "mon-article"
version = "1.0.0"
authors = ["Jean Dupont <jean@example.com>"]

[compile]
input = "main.typ"
output = "output/document.pdf"
format = "pdf"  # pdf, svg, png

[fonts]
paths = ["./fonts", "~/.fonts"]

[bibliography]
file = "references.bib"
style = "ieee"

[schema]
file = "schemas/article.json"
strict = true

[watch]
debounce = 300  # ms
clear = true    # Effacer le terminal

Sections de configuration

[project]

Option Type Description
namestringNom du projet
versionstringVersion du document
authorsarrayListe des auteurs
descriptionstringDescription du projet

[compile]

Option Type Defaut Description
inputstring"main.typ"Fichier source principal
outputstringautoChemin du fichier de sortie
formatstring"pdf"Format de sortie
rootstring"."Repertoire racine

[fonts]

Option Type Description
pathsarrayRepertoires de polices additionnels
fallbackstringPolice de secours

[bibliography]

Option Type Description
filestringChemin vers le fichier .bib
stylestringStyle de citation (apa, ieee, chicago...)
crossrefboolActiver l'API CrossRef

[watch]

Option Type Defaut Description
debounceint300Delai en ms avant recompilation
clearboolfalseEffacer le terminal
openboolfalseOuvrir le PDF automatiquement

Configuration globale

Fichier de configuration utilisateur (~/.config/nova/config.toml sur Linux/macOS, %APPDATA%\nova\config.toml sur Windows) :

# Configuration globale NovaType

[defaults]
template = "article"
citation_style = "ieee"
language = "fr"

[fonts]
paths = [
  "~/.fonts",
  "/usr/share/fonts"
]

[editor]
command = "code"  # Editeur par defaut

[pdf]
viewer = "evince"  # Lecteur PDF

Variables d'environnement

Variable Description
NOVA_CONFIGChemin vers le fichier de config global
NOVA_FONT_PATHRepertoires de polices (separes par :)
NOVA_TEMPLATE_PATHRepertoires de templates
NOVA_CACHE_DIRRepertoire de cache

Priorite des configurations

Les configurations sont appliquees dans cet ordre (la derniere gagne) :

  1. Valeurs par defaut de NovaType
  2. Configuration globale (~/.config/nova/config.toml)
  3. Configuration projet (nova.toml)
  4. Arguments en ligne de commande
  5. Variables d'environnement

Exemple complet

# nova.toml pour un article IEEE

[project]
name = "ieee-paper-2024"
version = "1.0.0"
authors = [
  "Jean Dupont <jean.dupont@univ-paris.fr>",
  "Marie Martin <marie.martin@cnrs.fr>"
]

[compile]
input = "paper.typ"
output = "build/paper.pdf"
format = "pdf"

[fonts]
paths = ["./fonts/ieee"]

[bibliography]
file = "references.bib"
style = "ieee"
crossref = true

[schema]
file = "schemas/ieee-article.json"
strict = true

[watch]
debounce = 200
clear = true

[plots]
theme = "ieee"
dpi = 300
Astuce

Utilisez nova init --template ieee-article pour generer automatiquement un nova.toml pre-configure.
