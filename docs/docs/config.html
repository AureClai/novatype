Configuration

nova.toml is the single source of truth for your NovaType project. All settings have sensible defaults — CLI arguments always take precedence.

nova.toml File

Each NovaType project has a nova.toml file at its root (generated by nova init):

# nova.toml - Project configuration

[project]
name = "my-article"
version = "0.1.0"
authors = ["John Doe <john@example.com>"]

[document]
main = "main.typ"
# template = "ieee-article"

[output]
format = "pdf"       # pdf, svg, png
directory = "build"

[bibliography]
style = "ieee"
bibliography = ["references.bib"]

[python]
python = "python"
figures_dir = "figures"
timeout = 60

[data]
results = "data/results.json"
params = "data/params.yaml"

# [fonts]
# paths = ["./fonts"]
# main = "Inter"
# mono = "Fira Code"

# [watch]
# debounce = 300
# clear = true
Zero-arg compile

With [document].main set, you can run nova compile with no arguments. The same applies to nova watch.

Configuration Sections

[project]

Project metadata. Used for identification and documentation.

Option Type Default Description
namestring—Project name (required)
versionstring"0.1.0"Project version
descriptionstring—Project description
authorsarray[]List of authors
licensestring—License identifier
keywordsarray[]Keywords for the project

[document]

Main document settings. Determines what file to compile.

Option Type Default Description
mainstring—Main source file (e.g. "main.typ"). Used by nova compile when no argument is given.
templatestring—Template name

[output]

Build output settings. Controls format and output directory.

Option Type Default Description
formatstring"pdf"Output format: pdf, svg, or png
directorystring"build"Output directory for build artifacts

[fonts]

Font paths and font mappings. Fonts can be specified as a simple name or a full specification with size, weight, and style.

Option Type Default Description
pathsarray[]Additional font directories
mainstring or table—Main body font
headingstring or table—Font for headings
monostring or table—Monospace font for code blocks
mathstring or table—Font for math expressions

Font values can be a simple string (main = "Inter") or a table with details:

[fonts.main]
family = "Open Sans"
size = "11pt"
weight = "regular"

[bibliography]

Citation style and bibliography files.

Option Type Default Description
stylestring"ieee"Citation style (apa, ieee, chicago...)
bibliographyarray[]Paths to .bib files

[python]

Configure Python figure generation. See Python Figures for a full guide.

Option Type Default Description
pythonstring"python"Python executable name or path
figures_dirstring"figures"Directory containing figure scripts
cache_dirstring".nova/cache"Directory for cached SVGs
timeoutint60Timeout per figure (seconds)
venvstring—Path to virtual environment
python_patharray[]Additional PYTHONPATH entries
envtable{}Environment variables for Python execution

[watch]

Watch mode settings for nova watch.

Option Type Default Description
debounceint300Delay in ms before recompilation
clearboolfalseClear terminal before each rebuild
ignorearray[]Glob patterns to ignore

[data]

External data files injected as Typst #let variables. Supports JSON, CSV, TOML, and YAML formats.

[data]
results = "data/results.json"    # becomes #let results = (...)
params = "data/params.yaml"      # becomes #let params = (...)
measurements = "data/data.csv"  # becomes #let measurements = (headers: (...), rows: (...))

Each key in [data] becomes a Typst variable name, and the value is the path to the data file. The data is automatically converted to Typst dictionaries and arrays, so you can use them directly in your document:

// In your .typ file, use data variables directly
The score was #results.score and the method was #results.method.
Format Extensions Typst output
JSON.jsonDicts and arrays
YAML.yaml, .ymlDicts and arrays
TOML.tomlDicts and arrays
CSV.csv(headers: (...), rows: (...))

Configuration Priority

Settings are applied in this order (last one wins):

  1. NovaType default values
  2. Project configuration (nova.toml)
  3. Command line arguments

Complete Example

# nova.toml for an IEEE article with Python figures and data

[project]
name = "ieee-paper-2024"
version = "1.0.0"
authors = [
  "John Doe <john.doe@univ-paris.fr>",
  "Jane Smith <jane.smith@cnrs.fr>"
]

[document]
main = "paper.typ"
template = "ieee-article"

[output]
format = "pdf"
directory = "build"

[fonts]
paths = ["./fonts/ieee"]
main = "Times New Roman"
mono = "Fira Code"

[bibliography]
style = "ieee"
bibliography = ["references.bib"]

[python]
python = "python3"
figures_dir = "figures"
venv = ".venv"
timeout = 120

[data]
results = "data/experiment-results.json"
benchmarks = "data/benchmarks.csv"

[watch]
debounce = 200
clear = true
Tip

Use nova init --template ieee-article to automatically generate a pre-configured nova.toml.
