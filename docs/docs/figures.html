Figures et images

Integrez des images, diagrammes et illustrations dans vos documents NovaType.

Image simple

#image("photo.png")

Image avec taille

// Largeur fixe
#image("photo.png", width: 10cm)

// Largeur proportionnelle
#image("photo.png", width: 50%)

// Hauteur fixe
#image("photo.png", height: 5cm)

// Les deux (peut deformer)
#image("photo.png", width: 10cm, height: 5cm)

Figure avec legende

#figure(
  image("resultats.png", width: 80%),
  caption: [Evolution des resultats sur 12 mois],
) <fig:resultats>

Comme illustre dans la @fig:resultats, on observe...

Placement et alignement

// Centre (par defaut pour figure)
#figure(
  image("photo.png", width: 50%),
  caption: [Ma photo],
)

// Image flottante a droite
#align(right)[
  #image("logo.png", width: 3cm)
]

// Image dans le texte
Voici un icone #image("icon.svg", height: 1em) dans le texte.

Formats supportes

Format Extension Recommandation
PNG .png Images avec transparence, captures d'ecran
JPEG .jpg, .jpeg Photos, images complexes
SVG .svg Graphiques vectoriels, logos, diagrammes
GIF .gif Images simples (premiere frame seulement)
Recommandation

Privilegiez le format SVG pour les graphiques et schemas. Il reste net a toutes les tailles.

Grille d'images

#figure(
  grid(
    columns: 2,
    gutter: 1em,
    image("img1.png"),
    image("img2.png"),
    image("img3.png"),
    image("img4.png"),
  ),
  caption: [Comparaison des quatre methodes],
) <fig:comparison>

Sous-figures

#figure(
  grid(
    columns: 2,
    gutter: 1em,
    [
      #image("avant.png")
      (a) Avant traitement
    ],
    [
      #image("apres.png")
      (b) Apres traitement
    ],
  ),
  caption: [Resultats du traitement d'image],
)

Image avec cadre

#figure(
  box(
    stroke: 1pt + gray,
    radius: 4pt,
    clip: true,
    image("screenshot.png", width: 100%)
  ),
  caption: [Capture d'ecran de l'interface],
)

Numerotation des figures

// Numerotation par defaut (1, 2, 3...)
#set figure(numbering: "1")

// Numerotation par chapitre (1.1, 1.2...)
#set figure(numbering: "1.1")

// Personnaliser le prefixe
#set figure.caption(separator: " -- ")

Placement automatique

// Figure flottante (placement automatique)
#figure(
  image("graph.png", width: 80%),
  caption: [Graphique des donnees],
  placement: auto,  // ou top, bottom
)

Dessins et formes

// Rectangle
#rect(width: 2cm, height: 1cm, fill: blue)

// Cercle
#circle(radius: 1cm, fill: red)

// Ellipse
#ellipse(width: 2cm, height: 1cm, fill: green)

// Ligne
#line(start: (0pt, 0pt), end: (2cm, 1cm), stroke: 2pt)

// Polygone
#polygon(
  fill: orange,
  (0pt, 0pt),
  (2cm, 0pt),
  (1cm, 1.5cm),
)

Diagramme simple

#figure(
  grid(
    columns: 3,
    gutter: 1em,
    align: center + horizon,

    rect(fill: rgb("#e0f2fe"), inset: 1em)[Entree],
    text(size: 24pt)[→],
    rect(fill: rgb("#2563eb"), inset: 1em)[
      #text(fill: white)[Traitement]
    ],
    [],
    text(size: 24pt)[→],
    [],
    [],
    rect(fill: rgb("#dcfce7"), inset: 1em)[Sortie],
    [],
  ),
  caption: [Schema du processus],
)
