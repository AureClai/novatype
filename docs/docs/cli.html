Reference CLI

Documentation complete de toutes les commandes disponibles dans la CLI NovaType.

Vue d'ensemble

$ nova --help

NovaType - Modern typesetting system

Usage: nova <COMMAND>

Commands:
  compile   Compile un document Typst en PDF/SVG/PNG
  init      Initialise un nouveau projet NovaType
  watch     Surveille les fichiers et recompile automatiquement
  validate  Valide les metadonnees d'un document
  template  Gere les templates

Options:
  -h, --help     Affiche l'aide
  -V, --version  Affiche la version

nova compile

Compile un document Typst en PDF, SVG ou PNG.

Syntaxe

nova compile <INPUT> [OPTIONS]

Arguments

Argument Description
<INPUT> Chemin vers le fichier source .typ

Options

Option Description Defaut
-o, --output <PATH> Chemin du fichier de sortie <input>.pdf
-f, --format <FORMAT> Format de sortie : pdf, svg, png pdf
--open Ouvre le document apres compilation false
--root <PATH> Repertoire racine pour les chemins relatifs Dossier courant
--font-path <PATH> Repertoires additionnels pour les polices -
-v, --verbose Active les logs detailles false
-q, --quiet Supprime les messages non-erreur false

Exemples

# Compilation simple
$ nova compile main.typ

# Compiler et ouvrir
$ nova compile main.typ --open

# Exporter en SVG
$ nova compile main.typ -f svg -o output.svg

# Exporter en PNG haute resolution
$ nova compile main.typ -f png -o figure.png

# Avec polices personnalisees
$ nova compile main.typ --font-path ./fonts/

nova init

Initialise un nouveau projet NovaType avec la structure recommandee.

Syntaxe

nova init <NAME> [OPTIONS]

Arguments

Argument Description
<NAME> Nom du projet (sera le nom du dossier)

Options

Option Description Defaut
-t, --template <TEMPLATE> Template a utiliser article
--no-git Ne pas initialiser de repository Git false

Templates disponibles

  • article - Article simple (defaut)
  • ieee-article - Format IEEE
  • nature-article - Format Nature
  • report - Rapport technique
  • book - Livre avec chapitres
  • presentation - Slides
  • cv - Curriculum vitae

Exemples

# Nouveau projet avec template par defaut
$ nova init mon-article

# Projet avec template IEEE
$ nova init conference-paper --template ieee-article

# Sans Git
$ nova init draft --no-git

Structure creee

mon-article/
├── main.typ        # Document principal
├── nova.toml       # Configuration du projet
├── references.bib  # Bibliographie
└── .gitignore      # Fichiers ignores par Git

nova watch

Surveille les modifications du fichier source et recompile automatiquement.

Syntaxe

nova watch <INPUT> [OPTIONS]

Options

Option Description Defaut
-o, --output <PATH> Chemin du fichier de sortie <input>.pdf
-f, --format <FORMAT> Format de sortie pdf
--debounce <MS> Delai avant recompilation (ms) 300
--clear Effacer le terminal avant chaque build false
--font-path <PATH> Repertoires additionnels pour les polices -

Exemples

# Surveillance simple
$ nova watch main.typ

# Avec nettoyage du terminal
$ nova watch main.typ --clear

# Delai de recompilation personnalise
$ nova watch main.typ --debounce 500
Astuce

Utilisez Ctrl+C pour arreter la surveillance.

nova validate

Valide les metadonnees (frontmatter) d'un document contre un schema JSON.

Syntaxe

nova validate <INPUT>... [OPTIONS]

Options

Option Description Defaut
--schema <PATH> Chemin vers un schema personnalise Schema du template
--strict Mode strict (frontmatter obligatoire) false

Exemples

# Valider un document
$ nova validate main.typ

# Valider plusieurs documents
$ nova validate chapter1.typ chapter2.typ chapter3.typ

# Avec schema personnalise
$ nova validate main.typ --schema my-schema.json

# Mode strict
$ nova validate main.typ --strict

nova template

Gere les templates NovaType.

Sous-commandes

Commande Description
nova template list Liste tous les templates disponibles
nova template info <NAME> Affiche les details d'un template
nova template install <SOURCE> Installe un template depuis un package ou chemin
nova template new <NAME> Cree un nouveau template personnalise

Exemples

# Lister les templates
$ nova template list

Templates disponibles:
  article        Simple article for general documents
  ieee-article   IEEE journal article format
  nature-article Nature journal formatting
  report         Business/technical reports
  book           Book with chapter support
  presentation   Slide presentations
  cv             Curriculum vitae/resume

# Informations sur un template
$ nova template info ieee-article

Template: ieee-article
Description: IEEE journal article format
Required fields: title, authors
Optional fields: abstract, keywords, bibliography

# Creer un template personnalise
$ nova template new mon-template

Variables d'environnement

Variable Description
NOVA_FONT_PATH Chemins additionnels pour les polices (separes par :)
NOVA_TEMPLATE_PATH Chemins additionnels pour les templates
NOVA_LOG Niveau de log (error, warn, info, debug, trace)

Codes de sortie

Code Signification
0 Succes
1 Erreur de compilation
2 Erreur de validation
3 Fichier non trouve
