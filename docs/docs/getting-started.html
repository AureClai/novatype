Installation

Installez NovaType sur votre systeme en quelques minutes.

Prerequis

Avant d'installer NovaType, assurez-vous d'avoir :

  • Rust (version 1.70 ou superieure) - Installer Rust
  • Git - Pour cloner le repository

Installation via Cargo

La methode recommandee est d'utiliser Cargo :

# Installer NovaType
$ cargo install nova-cli

# Verifier l'installation
$ nova --version
nova-cli 1.0.0

Installation depuis les sources

Pour installer la derniere version de developpement :

# Cloner le repository
$ git clone https://github.com/AureClai/novatype/novatype.git
$ cd novatype

# Compiler en mode release
$ cargo build --release

# L'executable se trouve dans target/release/nova
$ ./target/release/nova --version
Astuce

Ajoutez target/release a votre PATH pour acceder a nova depuis n'importe ou.

Installation sur Windows

# Avec PowerShell
> cargo install nova-cli

# Ou telecharger le binaire pre-compile
# depuis github.com/novatype/releases

Installation sur macOS

# Via Homebrew (bientot disponible)
$ brew install novatype

# Ou via Cargo
$ cargo install nova-cli

Installation sur Linux

# Via Cargo
$ cargo install nova-cli

# Sur Arch Linux (AUR)
$ yay -S novatype

Verification de l'installation

Apres l'installation, verifiez que tout fonctionne :

# Afficher l'aide
$ nova --help

NovaType - Modern typesetting system

Usage: nova <COMMAND>

Commands:
  compile   Compile un document
  init      Initialise un nouveau projet
  watch     Surveille et recompile automatiquement
  validate  Valide les metadonnees du document
  template  Gere les templates

Options:
  -h, --help     Afficher l'aide
  -V, --version  Afficher la version

Premier projet

Creez votre premier document NovaType :

# Creer un nouveau projet
$ nova init mon-article

# Se deplacer dans le dossier
$ cd mon-article

# Compiler le document
$ nova compile main.typ --open

Cette commande cree la structure suivante :

mon-article/
├── main.typ        # Document principal
├── nova.toml       # Configuration du projet
├── references.bib  # Bibliographie
└── .gitignore

Configuration de l'editeur

Visual Studio Code

Installez l'extension Typst pour la coloration syntaxique et l'autocompletion :

$ code --install-extension nvarner.typst-lsp

Neovim

Utilisez le plugin typst.vim avec votre gestionnaire de plugins prefere.

Autres editeurs

NovaType utilise la syntaxe Typst, donc tout editeur supportant Typst fonctionnera.
