Documentation NovaType

Bienvenue dans la documentation officielle de NovaType, le systeme de composition typographique moderne pour la redaction scientifique.

Qu'est-ce que NovaType ?

NovaType est un systeme de composition typographique de nouvelle generation, construit sur le moteur Typst. Il combine la qualite typographique de LaTeX avec une syntaxe moderne et intuitive, offrant une experience de redaction fluide pour les documents scientifiques et techniques.

Note

NovaType est entierement compatible avec la syntaxe Typst. Tout document Typst valide fonctionne avec NovaType.

Caracteristiques principales

Compilation instantanee

Visualisez vos modifications en temps reel avec notre moteur de compilation incremental.

Citations intelligentes

BibTeX, CrossRef API et Zotero integres avec 6+ styles de citation.

Visualisation de donnees

Creez des graphiques directement depuis vos fichiers CSV ou JSON.

Templates professionnels

IEEE, Nature, rapports, presentations et plus encore.

Architecture du systeme

NovaType est compose de plusieurs modules specialises :

Module Description
nova-cli Interface en ligne de commande (compile, init, watch, validate, template)
nova-core Moteur de compilation et orchestration
nova-schema Validation de metadonnees avec JSON Schema
nova-cite Gestion des citations et bibliographies
nova-plot Generation de graphiques SVG
nova-wasm Compilation WebAssembly pour le navigateur

Exemple rapide

Voici un exemple minimal de document NovaType :

// Configuration du document
#set document(title: "Mon Premier Document")
#set page(paper: "a4", margin: 2.5cm)
#set text(font: "Arial", size: 11pt, lang: "fr")

// Titre
#align(center)[
  #text(size: 24pt, weight: "bold")[Mon Premier Document]
]
