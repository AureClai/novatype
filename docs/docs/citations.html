Gestion des Citations

NovaType integre un systeme complet de gestion des citations avec support BibTeX, CrossRef API et Zotero.

Configuration

Configurez vos citations dans le frontmatter YAML :

---
title: "Mon Article"
bibliography: "references.bib"
citation_style: "ieee"
---

Styles de citation disponibles

Style Description Exemple
ieee IEEE (numerique) [1], [2], [3]
apa APA 7th edition (Smith, 2020)
chicago Chicago Manual of Style (Smith 2020)
harvard Harvard (Smith, 2020)
nature Nature journal 1
vancouver Vancouver (medical) (1)

Syntaxe des citations

Citation simple

// Citation dans le texte
Selon les travaux de @knuth1984, la typographie...

// Rendu IEEE: "Selon les travaux de [1], la typographie..."
// Rendu APA: "Selon les travaux de (Knuth, 1984), la typographie..."

Citation avec page

// Specifier une page
Comme explique dans @lamport1994[p. 42]...

// Rendu: "Comme explique dans [2, p. 42]..."

Citations multiples

// Plusieurs citations
Plusieurs etudes @smith2020 @jones2021 @martin2022 confirment...

// Rendu IEEE: "Plusieurs etudes [3]-[5] confirment..."
// Rendu APA: "Plusieurs etudes (Smith, 2020; Jones, 2021; Martin, 2022) confirment..."

Citation avec prefixe/suffixe

// Avec prefixe
@knuth1984[voir][chapitre 3]

// Rendu: "voir [1, chapitre 3]"

Fichier BibTeX

Creez un fichier references.bib avec vos references :

% Article de journal
@article{smith2020,
  author  = {Smith, John and Doe, Jane},
  title   = {Modern Typesetting Systems},
  journal = {Journal of Document Engineering},
  volume  = {12},
  number  = {3},
  pages   = {45--62},
  year    = {2020},
  doi     = {10.1234/jde.2020.001}
}

% Livre
@book{knuth1984,
  author    = {Knuth, Donald E.},
  title     = {The TeXbook},
  publisher = {Addison-Wesley},
  year      = {1984},
  isbn      = {0-201-13447-0}
}

% Conference
@inproceedings{jones2021,
  author    = {Jones, Marie},
  title     = {Next-Generation Document Systems},
  booktitle = {Proceedings of DocEng 2021},
  pages     = {1--10},
  year      = {2021}
}

% Site web
@online{typst2023,
  author  = {Typst GmbH},
  title   = {Typst Documentation},
  url     = {https://typst.app/docs},
  year    = {2023},
  urldate = {2024-01-15}
}

Bibliographie automatique

Ajoutez la bibliographie a la fin de votre document :

// Bibliographie avec style specifie
#bibliography("references.bib", style: "ieee")

// Ou utiliser le style du frontmatter
#bibliography("references.bib")

Resolution CrossRef

NovaType peut automatiquement recuperer les metadonnees depuis CrossRef :

// Dans le frontmatter, activez CrossRef
---
bibliography: "references.bib"
crossref_enabled: true
---

// Citez par DOI directement
Selon @doi:10.1234/example.2020...
Note

Les metadonnees CrossRef sont mises en cache localement pour accelerer les compilations suivantes.

Integration Zotero

Exportez votre bibliotheque Zotero en BibTeX et utilisez-la directement :

// 1. Exportez depuis Zotero: Fichier > Exporter la bibliotheque > BibTeX
// 2. Utilisez le fichier exporte

---
bibliography: "zotero-export.bib"
---

Personnalisation

Titre de la bibliographie

// Changer le titre
#bibliography(
  "references.bib",
  title: "References",
  style: "ieee"
)

Bibliographie sans titre

// Sans titre
#bibliography(
  "references.bib",
  title: none
)

Bibliographie multi-fichiers

// Plusieurs fichiers .bib
---
bibliography:
  - "articles.bib"
  - "books.bib"
  - "online.bib"
---

Exemple complet

---
title: "Revue de la litterature"
author: "Dr. Martin"
bibliography: "references.bib"
citation_style: "apa"
---

= Introduction

La composition typographique a considerablement evolue
depuis les travaux fondateurs de @knuth1984. LaTeX,
developpe par @lamport1994, reste la reference dans
le monde academique.

= Etat de l'art

Des approches recentes @smith2020 @jones2021 proposent
des alternatives plus modernes. Typst @typst2023
represente une avancee significative dans ce domaine.

= Conclusion

Les nouvelles technologies offrent des perspectives
prometteuses pour la redaction scientifique.

#bibliography("references.bib")
Conseil

Utilisez des gestionnaires de references comme Zotero ou Mendeley pour maintenir votre bibliotheque, puis exportez en BibTeX pour NovaType.
