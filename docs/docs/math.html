Equations mathematiques

NovaType offre un rendu mathematique de qualite professionnelle avec une syntaxe intuitive.

Syntaxe de base

Equations en ligne

La formule $ E = m c^2 $ est celebre.

Equations centrees

$ E = m c^2 $

Une equation sur sa propre ligne est automatiquement centree.

Equations numerotees

#set math.equation(numbering: "(1)")

$ E = m c^2 $ <eq:einstein>

Voir l'equation @eq:einstein pour la relation energie-masse.

Fractions

// Fraction simple
$ a/b $

// Fraction avec frac()
$ frac(a + b, c + d) $

// Fraction complexe
$ frac(1, 1 + frac(1, 1 + frac(1, x))) $

Racines

// Racine carree
$ sqrt(x) $

// Racine n-ieme
$ root(3, x) $     // Racine cubique
$ root(n, x) $     // Racine n-ieme

Sommes et produits

// Somme
$ sum_(i=1)^n i^2 $

// Produit
$ product_(i=1)^n i $

// Double somme
$ sum_(i=1)^n sum_(j=1)^m a_(i j) $

Integrales

// Integrale simple
$ integral f(x) dif x $

// Integrale definie
$ integral_a^b f(x) dif x $

// Integrale double
$ integral.double_D f(x,y) dif x dif y $

// Integrale de contour
$ integral.cont f(z) dif z $

Limites

// Limite
$ lim_(x -> infinity) f(x) $

// Limite a gauche/droite
$ lim_(x -> 0^+) 1/x = +infinity $

Matrices

// Matrice simple
$ mat(
  a, b;
  c, d
) $

// Matrice 3x3
$ mat(
  1, 0, 0;
  0, 1, 0;
  0, 0, 1
) $

// Matrice avec delimiteurs
$ mat(delim: "[",
  a, b;
  c, d
) $

Vecteurs

// Vecteur colonne
$ vec(x, y, z) $

// Vecteur avec fleche
$ arrow(v) $

// Vecteur gras
$ bold(v) $

Systemes d'equations

$ cases(
  x + y = 10,
  2x - y = 5
) $

Exemples complets

// Formule d'Euler
$ e^(i pi) + 1 = 0 $

// Integrale de Gauss
$ integral_(-infinity)^(+infinity) e^(-x^2) dif x = sqrt(pi) $

// Theoreme de Pythagore generalise
$ c^2 = a^2 + b^2 - 2 a b cos(gamma) $

// Equation de Schrodinger
$ i hbar frac(partial, partial t) Psi = hat(H) Psi $

// Serie de Taylor
$ f(x) = sum_(n=0)^infinity frac(f^((n))(a), n!) (x - a)^n $
Astuce

Utilisez des parentheses pour grouper les elements complexes : x^(a+b) au lieu de x^a+b.
