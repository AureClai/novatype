## Signaler une Vulnerabilite

La securite de NovaType est prise tres au serieux. Si vous decouvrez une vulnerabilite de securite, merci de nous la signaler de maniere responsable.

### Comment Signaler

**Ne pas** ouvrir une issue publique pour les vulnerabilites de securite.

1. **Email** : Envoyez un email decrivant la vulnerabilite (si un email de contact est configure)
2. **GitHub Security Advisories** : Utilisez la fonctionnalite [Security Advisories](https://github.com/AureClai/novatype/security/advisories/new) de GitHub

### Informations a Inclure

- Description de la vulnerabilite
- Etapes pour reproduire le probleme
- Impact potentiel
- Suggestion de correction (si possible)

### Processus de Reponse

1. **Confirmation** : Nous confirmerons la reception de votre rapport dans les 48 heures
2. **Evaluation** : Nous evaluerons la vulnerabilite et sa severite
3. **Correction** : Nous travaillerons sur un correctif
4. **Divulgation** : Une fois corrigee, nous publierons un avis de securite

### Delai de Reponse

- Confirmation initiale : 48 heures
- Evaluation : 1 semaine
- Correctif : Depend de la complexite (generalement 2-4 semaines)

## Bonnes Pratiques de Securite

### Pour les Utilisateurs

- Gardez NovaType a jour avec la derniere version
- Verifiez l'integrite des binaires telecharges
- Ne compilez pas de documents `.typ` provenant de sources non fiables

### Pour les Contributeurs

- Ne committez jamais de secrets ou credentials
- Utilisez des dependances a jour
- Suivez les bonnes pratiques de securite Rust
- Faites attention aux injections et aux debordements
